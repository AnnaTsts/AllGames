# Генерація слів/фраз для гри "Аліас" (українською)

## Мета
Згенерувати банк слів і фраз для party-гри типу "Аліас" (пояснюєш слово, інші вгадують).
Кожен запис — це **одне слово або фраза до 5 слів**, українською мовою.

Результат — файл(и) з даними, розбитими по категоріях і рівнях складності.

## Розподіл складності (для КОЖНОЇ категорії окремо)

- 🟢 easy — 40%
- 🟡 normal — 30%
- 🔴 hard — 30%

Приклади розрахунку:
- 5000 → 2000 easy / 1500 normal / 1500 hard
- 1000 → 400 easy / 300 normal / 300 hard
- 450 → 180 easy / 135 normal / 135 hard

Критерій складності:
- **easy** — знає майже кожен, пояснюється за 1 просте слово-асоціацію (напр. "кіт", "дощ")
- **normal** — треба трохи подумати або описати кількома словами (напр. "дежавю", "піксельоване фото")
- **hard** — рідкісне слово, вузькоспеціалізований термін, складна абстракція або дуже конкретна деталь (напр. власні імена другого плану, наукові терміни, специфічний сленг)

## Правила для самих слів/фраз

1. Мова — виключно українська (без суржику, без калькованих з рос. слів, якщо є нормальний укр. відповідник).
2. Довжина — 1–5 слів. Фраза має бути природною ("їхати зайцем", а не громіздкий опис).
3. Слово/фраза має бути **пояснюваною жестами/словами** в грі — уникати надто абстрактних або нез'ясовних понять.
4. **Без дублікатів** всередині категорії. Дублікати між різними категоріями допустимі (крім "Повний рандом", яка може перетинатись з усіма).
5. Уникати образливих етнічних/расових слурів, розпалювання ненависті, реальних приватних осіб (окрім публічних персон в "Відомі люди" — лише публічний контекст).
6. Для категорії **"18+ Те, що ніхто не говорить"**: дозволені грайливі, ніякові, дорослі теми (сленг про стосунки, тіло, незручні ситуації), але **без** відверто порнографічного змісту, без деталізації статевих актів, без неповнолітніх у будь-якому контексті. Тримати рівень "незручний жарт за столом з друзями", а не еротика.
7. Для "Люди та стосунки" / "Погані вчинки" — можна гумористично і саркастично, але без заклику до насильства.
8. Слова мають бути **різноманітними всередині категорії** — не повторювати одну й ту саму тему 50 разів.

## Формат виводу

Один файл на категорію + один зведений файл. Формат: **JSON** (масив об'єктів) + опційно CSV.

```json
{
  "category": "Кіно",
  "emoji": "🎬",
  "count": 1000,
  "words": [
    { "word": "Зелена миля", "difficulty": "normal" },
    { "word": "Оскар", "difficulty": "easy" },
    { "word": "неонуар", "difficulty": "hard" }
  ]
}
```

Зведений файл `all_words.json`:
```json
[
  { "word": "...", "category": "Кіно", "emoji": "🎬", "difficulty": "easy" },
  ...
]
```

Також згенерувати `all_words.csv` з колонками: `word,category,emoji,difficulty`.

## Як виконувати (для Claude Code)

Оскільки обсяг великий (~35 400 записів), генерувати **пакетами** (батчами), а не за один прохід:

1. Для кожної категорії — генерувати батчами по 50–100 слів за раз, з чітким прод-промптом, що включає:
   - назву категорії,
   - потрібний рівень складності для цього батчу,
   - список уже згенерованих слів у цій категорії (щоб уникати дублікатів),
   - правила з розділу "Правила для самих слів/фраз".
2. Після кожного батчу — дедуплікація (case-insensitive, з урахуванням відмінків за потреби) перед додаванням у загальний список.
3. Рахувати прогрес до потрібної кількості easy/normal/hard окремо, зупинятись, коли кожен рівень заповнений.
4. Після завершення категорії — зберегти проміжний JSON-файл для неї в `output/<категорія>.json`, щоб не втратити прогрес при збоях.
5. В кінці — зібрати все в `all_words.json` і `all_words.csv`, порахувати фінальну статистику (кількість по категоріях і складностях) і вивести звіт.
6. Провести фінальну перевірку:
   - немає дублікатів в межах категорії,
   - розподіл складності відповідає 40/30/30 (± кілька одиниць через округлення),
   - всі фрази ≤ 5 слів,
   - немає порожніх/дуже коротких (менше 2 символів) записів.
